# 개인종합자산관리계좌(ISA) 안내

ISA(개인종합자산관리계좌)의 유형(신탁형·일임형·중개형), 납입한도, 의무가입기간, 비과세·분리과세 세제혜택과 서민형·농어민형 요건을 설명하는 금융위원회 공식 안내입니다. 세제 한도는 정책 개정에 따라 변동하므로 출처 확인 대상으로 표시합니다.
