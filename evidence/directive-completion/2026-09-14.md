외부 공개 추천 승인은 이 지시서의 완료 항목이 아니다. 지시서가 명시한 `Public recommendation=false`를 유지한다. 공식 자료에서 확인하지 못한 값은 임의로 채우지 않는다.

로컬 최종 검증: 지식 테스트 53개, MCP 테스트 111개 및 타입 검사 통과. 로컬 Worker 실제 회귀 120/120, transport error 0. 예금·적금 positive market comparison 2개 시나리오 통과. npm audit 취약점 0. GitHub 수동 release 검증은 별도 실행 결과로 남긴다.

광주은행 TD11300027000은 복리 방식은 확인했으나 복리 주기 근거가 없어 금액 계산을 null로 반환한다. 해당 상품의 계산 가능성을 검증된 것으로 표시하지 않는다. 실패 HTTP 응답은 header와 body를 artifact에 보존하며, 악성·무한 응답에 대한 16MiB 한도 또는 timeout 발생 시 명시적 body_read_error와 실패 상태를 기록한다.
